# Klik KBBI - Kamus Instan (Chrome Extension)

Ekstensi Google Chrome (Manifest V3) yang dirancang untuk mencari definisi kata secara instan langsung dari situs resmi KBBI Kemendikdasmen tanpa harus membuka tab baru. Proyek ini dibangun dengan metode *Live Web Scraping/Parsing* dan dikembangkan melalui pendekatan *Vibe Coding* berkolaborasi dengan AI.

Proyek ini diajukan sebagai karya dalam kompetisi **JuaraVibeCoding**.

---

## ✨ Fitur Utama

- **Pencarian Cepat via Blok Teks (Context Menu):** Cukup sorot (block) kata di halaman web mana saja, klik kanan, dan pilih *"Cari definisi di KBBI"*. Hasil akan muncul langsung di dekat kursor berupa kotak melayang (*floating tooltip*).
- **Pencarian Manual (Popup Menu):** Klik ikon ekstensi di toolbar peramban untuk membuka kolom pencarian minimalis untuk mengetik kata secara manual.
- **Data Selalu Akurat & Up-to-Date:** Sistem melakukan *fetch* data langsung ke domain resmi kementerian, memastikan definisi kosakata yang didapat selalu mutakhir (KBBI Edisi VI).
- **Antarmuka Minimalis & Modern:** Desain UI dirancang bersih dengan sudut melengkung (*rounded corners*), bayangan halus (*soft shadow*), serta animasi transisi yang nyaman di mata.
- **Ringan & Efisien:** Bebas dari beban *database* lokal yang besar, menghemat penggunaan memori (RAM) peramban.
