# Klik KBBI - Kamus Instan (Chromium Extension)

Ekstensi peramban berbasis Chromium (Manifest V3) yang dirancang untuk mencari definisi kata secara instan langsung dari situs resmi KBBI Kemendikdasmen tanpa harus membuka tab baru. Proyek ini dibangun dengan metode *Live Web Scraping/Parsing*

---

## ✨ Fitur Utama

- **Pencarian Cepat via Blok Teks (Context Menu):** Sorot teks, klik kanan, pilih *"Cari definisi di KBBI"*. Hasil muncul langsung di dekat kursor.
- **Pencarian Manual (Popup Menu):** Klik ikon ekstensi di toolbar untuk mencari kata secara manual.
- **Data Akurat & Up-to-Date:** *Fetch* data langsung ke domain resmi kementerian (KBBI Edisi VI).
- **Antarmuka Minimalis:** Desain UI bersih dengan *rounded corners*, bayangan halus, dan transisi yang mulus.
- **Ringan & Efisien:** Bebas *database* lokal, hemat penggunaan memori RAM peramban.

---

## 🚀 Panduan Instalasi Lokal

Ekstensi ini dapat dipasang secara manual pada peramban berbasis Chromium (Google Chrome, Edge, Brave, Opera, dll). Berikut langkah singkatnya:

1. Unduh repositori ini dengan mengeklik tombol **Code > Download ZIP**.
2. Buka menu pengaturan ekstensi di peramban Anda (klik ikon tiga titik di pojok kanan atas > pilih **Extensions** > **Manage Extensions**).
3. Aktifkan **Developer mode** di pojok kanan atas halaman.
4. Pasang ekstensi dengan salah satu cara berikut:
   - **Cara Instan:** Tarik dan lepas (*drag and drop*) file `.zip` yang baru saja diunduh langsung ke tengah halaman ekstensi.
   - **Cara Alternatif:** Ekstrak file `.zip` tersebut, klik tombol **Load unpacked**, lalu pilih folder hasil ekstraksi.
5. Selesai! Sematkan (*pin*) ikon Klik KBBI di toolbar agar lebih mudah diakses.

---

## 📖 Cara Penggunaan

1. Buka artikel atau situs web apa saja.
2. Sorot (blok) kata yang ingin dicari artinya.
3. Klik kanan, lalu pilih opsi **"Cari definisi '[kata]' di KBBI"**.
4. Kotak *tooltip* akan muncul menampilkan definisi secara instan. Klik area di luar kotak untuk menutupnya.
5. Untuk pencarian manual, klik ikon **Klik KBBI** di toolbar atas.
